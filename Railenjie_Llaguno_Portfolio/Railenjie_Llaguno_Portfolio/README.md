# Railenjie Llaguno Portfolio

A responsive portfolio with a distinct forest-green, mint, and lime theme, animated decorative elements, reveal-on-scroll effects, mobile navigation, and three project concept cards.

## Files
- `index.html` — page structure
- `style.css` — responsive design and animations
- `script.js` — mobile navigation and scroll reveals
- `assets/portfolio-visual.png` — generated portfolio visual

## Run locally
Extract the ZIP and open `index.html` in a browser. Google Fonts require an internet connection.
